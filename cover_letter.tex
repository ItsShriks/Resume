Developing safe, intelligent autonomous capabilities for UAV platforms -- from simulation through to real-world flight -- is precisely the engineering challenge I have been building toward. Your role as an Autonomous Systems Engineer combines guidance, navigation and control (GNC) software development with sensor fusion and real-world flight testing: the exact intersection where my academic and applied experience sits.

\vspace{2pt}

My profile aligns with the role's core requirements in the following areas:

\begin{itemize}[leftmargin=*, itemsep=3pt, parsep=0pt, topsep=2pt]

    \item \textbf{Sensor Fusion \& State Estimation for UAV Platforms (GPS, IMU, LiDAR, RGB-D Camera)}:\\
    As a Research Assistant at H-BRS, I performed camera--LiDAR--IMU calibration and multi-sensor fusion for UAV state estimation, developing 3D spatial segmentation pipelines in C++17/Python (PyTorch, Open3D, CUDA) that processed real drone sensor data under strict latency constraints. I also built and benchmarked SLAM-based localisation on a low-cost LiDAR scanner, directly applicable to airborne GNC workflows.

    \item \textbf{Autonomous Navigation, Mission Planning \& ROS2 Integration (ROS2, C++17, Python, Linux)}:\\
    As Perception and Navigation Core Member of b-it bots @Home at H-BRS, I implemented autonomous navigation and sensor fusion pipelines (SLAM, Nav2, YOLO, RGB-D/LiDAR) in ROS2, enabling robust scene understanding and mission execution on physical platforms. I develop modular C++17 and Python software on Jetson and RPi boards and maintain reproducible CMake/Git/CI-CD workflows across the team.

    \item \textbf{HIL/SIL Testing \& Real-Time Validation (Embedded Hardware, Gazebo Simulation)}:\\
    I have conducted hardware-in-the-loop testing across multiple platforms -- validating autonomous behaviours, profiling real-time execution bottlenecks, and calibrating sensors under operational conditions. Simulation environments including Gazebo and MuJoCo have been integral to my development workflow for testing before physical deployment.

    \item \textbf{GNC Software \& Flight Data Analysis (C++, Python, SLAM, State Estimation)}:\\
    My master's thesis couples a VLA-compatible MPC planner with a TSID controller via an asynchronous ROS2 bridge, requiring rigorous analysis of trajectory data and control-loop performance -- skills that translate directly to analysing flight data and improving autonomous system reliability for UAV operations.

\end{itemize}
