\vspace{2pt}

My profile aligns with your core requirements in the following areas:

\begin{itemize}[leftmargin=*, itemsep=3pt, parsep=0pt, topsep=2pt]

    \item \textbf{Autonomous Navigation, Obstacle Avoidance \& ROS2 Development}:\\
    As Perception and Navigation Core Member at b-it bots @Home (H-BRS), I implemented autonomous navigation and sensor fusion pipelines (SLAM, Nav2, YOLO, RGB-D/LiDAR) in ROS2, enabling robust obstacle avoidance and mission execution on physical platforms. I develop modular C++17 and Python software on Jetson and RPi boards and have direct experience with PX4 and ArduPilot autopilot frameworks.

    \item \textbf{Control Algorithms \& Real-World Testing}:\\
    At Sakar Robotics, I developed autonomous robot control algorithms in Python/C++ and interfaced them with low-level hardware for real-time closed-loop execution; I led HIL testing and sensor bring-up across multiple hardware platforms. I have also participated in field validation campaigns, profiling real-time execution bottlenecks and iterating on software to meet operational requirements.

    \item \textbf{Image Processing \& Computer Vision (OpenCV, PyTorch)}:\\
    I have applied OpenCV and PyTorch-based perception pipelines across several projects -- from real-time 3D object detection on drone-collected LiDAR data to YOLO-based scene understanding on mobile robots -- consistently targeting performance under resource constraints on embedded hardware.

\end{itemize}
