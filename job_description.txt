The DLR Institute of Communications and Navigation is dedicated to mission-oriented research in selected areas of communications and navigation. Its work ranges from the theoretical foundations to the demonstration of new procedures and systems in a real environment and is embedded in DLR's Space, Aeronautics, Transport, Security and Digitalization programmes.

 

What to expect:

In decentralized swarm systems, achieving reliable navigation in GNSS-denied environments remains a critical challenge. The DLR's swarm navigation framework addresses this by leveraging inter-agent ranging to establish a self-organizing localization network. However, running these real-time algorithms requires efficient execution on resource-constrained hardware. Working in close collaboration with the team, you will support the practical implementation and architectural design of the DLR swarm navigation system for microcontrollers and single-board computers.

 

Your tasks:

Contribute to the design of a hardware-independent, modular software architecture to enable flexible deployment across various hardware platforms
Implement and test software modules to execute the DLR swarm navigation algorithms on microcontrollers and single-board computers
Jointly design and conduct practical system tests
Document the developed software architecture and code structures
 

Your profile: 

Student in Computer Science, Electrical Engineering, Mechatronics, or a related field.
Strong programming skills in C++ or Rust for hardware-near development.
Experience with embedded systems (e.g., ESP32, Raspberry Pi); knowledge of hardware-level concepts (I²C, SPI, Interrupts) is an advantage.
Good knowledge of software engineering, including Clean Code, Design Patterns, and Software Architectures.
Familiarity with modern development tools like Git and CI/CD pipelines.
