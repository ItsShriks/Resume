\section{Summary}
M.Sc. student in Autonomous Systems at Hochschule Bonn-Rhein-Sieg (graduating Feb 2027) working on 3D computer vision for robots: point cloud segmentation, registration, object detection and keypoint-based tracking in \textbf{Python, C++ and PyTorch}. Built a label-free LiDAR segmentation pipeline with PointNet++ (\textbf{0.80 validation mIoU}, preliminary) and registered field annotations to the point clouds with RANSAC + ICP at \textbf{98.8\% inliers} (0.11\,m RMS). Person-following on the Toyota HSR with a \textbf{95\% tracking success rate}, an offline OCR and layout-detection pipeline with 90--95\% accuracy on low-end CPUs, and a YOLOv11 document-field detector fine-tuned on synthetic data. Uses ROS 2 day to day.
